# Human review checklist

Before accepting a plan:

- Confirm every decision is an actual decision rather than a proposal.
- Read source quotations in full context; check the task, owner, date, and dependency meaning.
- Resolve unknown details instead of allowing the model to guess.
- Review urgency scores as suggestions, not business judgment.
- Verify prerequisites are complete in the authoritative work system.
- Obtain separate authorization for any external action.
- Review the exact follow-up wording before sending it.

## Public example policy

The included fictional roles are Demo Coordinator, Demo Designer, and Demo Reviewer. They do not represent real people. There are no customer identities, emails, recordings, real meeting excerpts, operational figures, or access tokens.

The program cannot verify whether data is truly fictional. Its synthetic flag is only a required assertion. Review every file and its Git history before publication; deleting a secret in a later commit does not remove it from earlier history. Do not upload real meeting inputs or generated outputs to a public repository.
